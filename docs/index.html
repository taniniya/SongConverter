SongConverter

太鼓の達人 TJA ファイル管理ツール

曲フォルダの自動並び替え、段位認定コースの生成、OpenTaiko 段位の変換。 TJA 周りの3つの作業を、1つの Windows アプリで行えます。

最新版 v1.2.0 をダウンロード GitHub リポジトリ

Windows 10 / 11（64bit）・ .NET ランタイム同梱でインストール不要 ・ 無料（MIT ライセンス）

機能 Features

3つのツールと、このカスタム版ならではの改良点。

SONGSORTER並び替え

esegit（太鼓の達人データベース）から曲リストを取得し、ダウンロードした TJA の曲フォルダを公式の並び順に自動で整理します。

DANGENERATOR段位生成

太鼓の達人 Wiki の段位ページから、TaikøNauts 用の段位認定コースファイルを自動生成します。

DANCONVERTOR段位変換

OpenTaiko 形式の段位 TJA を、TaikøNauts で使える形式に変換します。

PROGRESS大きな進行状況パネル

処理の進み具合がひと目で分かる大型パネル（進捗バー＋パーセント＋処理数＋経過時間）を搭載。

MODERN UIモダンなデザイン

左サイドバー＋ヘッダーのレイアウト、角丸ボタン、ダークテーマ。最近の Windows アプリ風の見た目に刷新しました。

SINGLE FILEインストール不要

exe 1ファイルで動作します。.NET ランタイム同梱なので、ダウンロードしてそのまま実行できます。

使い方 Usage

左のサイドバーからツールを選んで使うだけです。

並び替え

  1. 「リスト取得」で esegit からカテゴリ別の曲リストを取得
  2. 曲をダウンロードするフォルダを選択
  3. 「整理する」を押すと公式順に並び替え

段位生成

  1. 太鼓の達人 Wiki の段位ページの URL を入力
  2. 出力先フォルダを選択
  3. 「段位を生成」で TaikøNauts 用ファイルを生成

段位変換

  1. OpenTaiko の段位 TJA フォルダを選択
  2. 出力先を選択
  3. 「変換」で TaikøNauts 形式に変換
